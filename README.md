# 异形数独 Jigsaw Sudoku

一个基于 Web 的异形数独（Jigsaw Sudoku）谜题游戏，原生 SVG 渲染，内置逻辑解题器。
支持 4×4 / 6×6 / 9×9 等不规则宫尺寸与任意 4..25 方形异形题面、自定义画宫、图片导入（识图实测 14×14）。

## 在线体验

```bash
npm install
npm start
```

`npm start` 会等开发服务就绪后用默认浏览器打开 **http://127.0.0.1:5196/**。

> 也可以用 `npm run dev`，但不会自动打开浏览器。

## 游戏规则

- 在 N×N 格中填入 1..N（9×9 用 1..9，14×14 用 1..9 与 A..E），每行、每列数字不重复
- 每个由粗线围成的不规则宫内数字也不能重复
- 题面预填数字不能修改

## 操作

| 操作 | 说明 |
|------|------|
| 左键点格 | 选中格子；未选数字面板时按 1→2→…→N→空 循环填数 |
| 数字面板 | 先点一个数字，再点格子即直接填该数；「清除」用于擦除；再点一次数字回到循环模式 |
| 数字键 1–9 | 给选中格填 1–9（14×14 时 Shift+A…E 填 10–14） |
| 0 / Backspace / Delete | 清除选中格（没有选中格时 `0` 为视图复位） |
| 方向键 | 移动选中格 |
| 右键点格 | 清除该格 |
| 滚轮 / 中键拖拽 | 缩放 / 平移画布 |
| Z / Shift+Z / Y | 撤销 / 重做 |
| C / H / S / Esc | 检查 / 提示一格 / 显示解 / 清空 |
| R / L / P / M | 随机抽题 / 逻辑解题 / 暂停回放 / 音效开关 |
| 0 / + / - | 视图复位 / 放大 / 缩小 |

## 数据存放

运行 `npm start` / `npm run dev` 时，题库、进度和上次题目保存在项目内 `data/` 目录；静态部署时自动降级到浏览器 localStorage。

## 功能

- **题库**：内置多道 9×9 异形题，题目均校验唯一解；图片导入的大尺寸题放在独立文件里，不会被重新生成覆盖
- **任意宫形**：`regions` 每格一个宫号，宫的数量与形状都不要求规则；渲染、校验、求解、逻辑回放全部按实际宫形工作
- **大尺寸支持**：任意正方形 N×N（4..36，实际使用 9 / 14），渲染/命中/校验/求解/逻辑回放按实际宽高工作
- **实时校验**：冲突与违规位置即时高亮，满足的条件同步变灰
- **逻辑解题**：规则引擎逐帧回放，显示每一步理由（基础规则 / 高级定式 / LoL / 反证 / 回溯分别标注）；回放中按钮变为停止，按 `P` 暂停/继续
- **提示一格 / 显示解**：提示优先揭示所有解一致的格子，显示解直接填入可行答案
- **撤销/重做**：按手势分组，一次拖拽只需一步撤销
- **进度保存**：自动保存当前题目进度，刷新不丢失
- **音效特效**：Web Audio 合成拨弦、水滴与落子动画，无外部音频资源
- **缩放/平移**：滚轮缩放，中键或 `Shift` 拖拽平移

- **自定义题板（画宫 / 填数）**：先切到「画宫」画出不规则宫（点击或键盘 0-9 / A-Z 设置宫号，退格清空），
  再切到「填数」录入预填数字，最后「载入题板」；支持 4..25 方形题板，保存后可编辑、两步确认删除。

## 逻辑定式

逻辑解题器按「候选集」推理，回放里每帧标注所用定式（规则 1–5）：

| 规则 | 定式 | 说明 |
|------|------|------|
| 1 | 唯一候选 | 行/列/宫（异形宫同规则）已用数字排除后只剩一个候选 |
| 2 | 单元隐性唯一 | 某数字在行/列/异形宫内只剩一个位置 |
| 3 | 高级集合定式 | 宫-行/列交叉（pointing / claiming）、显性/隐性数对与三数组、X-Wing、Swordfish、Skyscraper、XY-Wing、XYZ-Wing、宫集 Hall 约束、剩余法 LoL、唯一矩形 |
| 4 | 反证 | 逐个试填，若立刻矛盾则该数字成立（带完整传播的兜底推理） |
| 5 | 回溯试探 | 规则 1–4 都不够时用回溯补完 |

- 唯一矩形依赖「题面唯一解」这一前提，只在确认唯一解后启用（9×9 及以下自动校验，大棋盘默认关闭）。
- 剩余法 LoL（Law of Leftovers）：取连续 k 行/列，完全落在其中的宫记作 A，剩余格中每个数字恰好出现 k-|A| 次；据此排除候选或直接落子（仅标准异形：宫数 = N 且每宫 N 格时成立）。
- 规则 1–3 全部是「候选消除 / 落子」，每一步都能由集合条件证明，不针对具体题目硬编码。
- 反证与回溯保留为兜底：规则 4 会先做单格试填验证，规则 5 只在逻辑完全推不动时补完。
- `npm run audit` 会统计每题的基础 / 高级定式 / 反证 / 回溯帧数，可直接对比定式效果。

## 技术栈

- Vite + TypeScript
- 原生 SVG（无框架）
- Web Audio 合成音效（无外部资源）
- localStorage / 项目内 `data/` 存储进度与题库

## 项目结构

```
src/
  main.ts
  core/
    app.ts / ui.ts / view.ts      界面、交互、缩放、回放控制
    store.ts / library.ts         题库、进度、上次题目存储
    audio.ts / fx.ts              音效与落子特效
  game/
    adapter.ts                    游戏规则接入
    rules.ts                      规则引擎：基础传播 + 高级定式 + LoL（任意 N / 任意宫形）
    logic.ts                      逻辑解题回放
    render.ts / state.ts          SVG 渲染与盘面状态
    validate.ts / solver.ts       实时校验与回溯求解
    puzzles.ts                    题库加载与解码（任意 N / 任意宫形）
    puzzles-data.ts               npm run gen 生成的内置题（会被覆盖）
    imported-puzzles.ts           图片导入题（不影响内置题，不被 gen 覆盖）
```

## 尺寸支持矩阵

| 尺寸 | 宫形 | 内置题 | 自定义题板（画宫/填数） | 图片导入 | 求解/校验/逻辑回放 |
|------|------|--------|------------------------|----------|------------------|
| 4×4 | 不规则（4 宫，每宫 4 格） | ✅ 2 题 | ✅ | ✅（4..25 通用） | ✅ |
| 6×6 | 不规则（6 宫，每宫 6 格） | ✅ 2 题 | ✅ | ✅ | ✅ |
| 8×8 | 不规则（8 宫） | —（可自定义/导入） | ✅ | ✅ | ✅ |
| 9×9 | 不规则（9 宫；旧题库原样保留） | ✅ 6 题 | ✅ | ✅ | ✅ |
| 10×10 | 不规则（10 宫） | — | ✅ | ✅ | ✅ |
| 12×12 | 不规则（12 宫） | — | ✅ | ✅ | ✅ |
| 14×14 | 不规则（14 宫） | — | ✅ | ✅（识图实测月图） | ✅ |
| 16×16 | 不规则（16 宫） | — | ✅ | ✅ | ✅（大棋盘有求解预算限制） |
| 其它 4..25 方形 | 任意宫数与宫形（宫数不必等于 N，每宫 ≤ N 格） | — | ✅ | ✅ | ✅ |

- 数值显示：1–9 显示为数字，10–25 显示为 A–P（`board` 编码用 36 进制，一格一个字符）。
- `regions` 每格一个宫号（0..35），宫数 1..36、宫形任意，不要求宫数等于 N；渲染、命中、校验、求解、逻辑回放全部按实际宫形工作。
- 编码兼容：`board = givens|regions`，旧 9×9 题库里的 `'0'..'9'` 与新编码完全一致，进度存档同样兼容。
- 内置题库：旧 9×9 六题保持字节级不变；多尺寸题在 `puzzles-extra-data.ts`。
- 限制：只支持正方形题面；自定义/导入边长 4..25；非连通宫也能编辑，但有效题面通常需要连通宫。

## 从图片导入题库

```bash
npm run import-image -- month.png --verify                    # 预览识别结果与宫形，并校验唯一解
npm run import-image -- month.png --append                     # 追加到识图题库（需唯一解）
npm run import-image -- puzzle.png --box 3                     # 宫形识别失败时强制按 3×3 标准宫
npm run import-image -- puzzle.png --json out.json             # 只导出 JSON，不写题库
npm run import-image -- puzzle.png --map "3,4=G,5,1=7"         # 人工覆盖误识别的格子
```

说明：

- Playwright + Edge 自动识别网格线、粗宫界线（每条格线量“墨量”，2-means 分粗细，再四连通洪泛得到宫形）与数字/字母字形。
- 终端会打印识别结果与宫形矩阵（每个宫的格数应等于 N），`--verify` 调项目 solver 校验唯一解并生成参考解。
- `--map` 人工覆盖格子，坐标 0 基，格式 `x,y=字符`（列,行）；`--box N` 可在宫形识别失败时强制标准宫。
- `--append` 把题面（含不规则宫编号）写入 `src/game/imported-puzzles.ts`，刷新后即出现在左侧题库并可游玩；
  写入用 36 进制编码，所以 14×14 的 10–14（A–E）与 14 个宫都能存。
- `npm run gen` 只重写 `src/game/puzzles-data.ts`（内置题），不会覆盖 `imported-puzzles.ts`。
- 识别依赖图片字体与模板库近似度，个别格可能需要 `--map` 修正后重跑。

## 命令

```bash
npm run dev       # 开发服务
npm start         # 开发服务 + 自动打开浏览器

npm run check     # 审计题库（内置 + 识图导入，任意 N / 任意宫形）
npm run verify    # 参考解、逻辑回放与交互验证
npm run audit     # 逐题审计逻辑解题（基础/高级定式/反证/回溯帧 + 推满率）
```
